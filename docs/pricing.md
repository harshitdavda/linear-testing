# Pricing rules

- Discount codes: `WELCOME10` (10% off), `HALFOFF` (50% off). `BLACKFRIDAY30` (30% off, until 2026-11-30 23:59:59 UTC). Codes are case-insensitive.
- A code with an expiry date is rejected once that moment has passed.
- Tax is applied after the discount.
- All amounts are integer cents and rounded to the nearest cent.
